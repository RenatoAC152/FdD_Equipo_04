# Productos comerciales

El [informe del Entregable 2](<../../Fundamentos%20de%20dise%C3%B1o/Entregables/Entregable%202/Entregable_2_HORIZON%20%287%29_compressed.pdf#page=6>) compara Intello Sort, OneThird Fresh Produce Scanner y KeepAlert Hand.

| Referencia del informe | Uso en la comparación |
| --- | --- |
| Intello Sort | Clasificación automatizada como referencia de inspección en línea. |
| OneThird Fresh Produce Scanner | Evaluación no destructiva de calidad y vida útil mediante escaneo. |
| KeepAlert Hand | Instrumento portátil considerado en el análisis de alternativas de inspección. |

El [Desk Research del Taller 6](<../../Fundamentos%20de%20dise%C3%B1o/Talleres/Taller_06/Taller_6_Desk_Research_Vancouver.pdf>) reúne además referencias como Winnow Vision y OneThird.
