# Partes · HORIZON

La envolvente indicada para la Rev E es **193,7 × 172,5 × 179,5 mm**. La ficha de cinco piezas imprimibles distingue estas funciones.

| Pieza Rev E | Función |
| --- | --- |
| Cuerpo inferior | Base del gabinete y apoyo de la cámara de inspección. |
| Cuerpo superior | Completa la cámara y la unión con la zona de iluminación. |
| Tapa | Cierra el conjunto y permite acceso de servicio según el montaje. |
| Consola | Aloja la interfaz frontal y sus mandos. |
| Puerta con cierre magnético | Permite introducir la muestra y cerrar la cámara durante la inspección. |
