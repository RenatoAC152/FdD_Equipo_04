# Onshape · VFINAL

La ficha de la Rev E especifica una envolvente de **193,7 × 172,5 × 179,5 mm** para el gabinete, cinco piezas imprimibles, seis planos de detalle y una vista explosionada.

El enlace disponible en el Taller S11 corresponde al modelo corregido de Onshape. El archivo fuente del enlace no identifica una versión congelada con la letra E, así que conviene cotejar la revisión en Onshape antes de fabricar.
