# Certificados y normas de diseño

## Aplicación al módulo mecánico

El equipo aplicó estas referencias al definir materiales para la zona de muestra, la separación de la bahía electrónica y las medidas de seguridad del gabinete. [Lista de exigencias](../../../Fundamentos%20de%20dise%C3%B1o/Talleres/Taller_04/Taller_04_L.E..pdf) · [Módulo mecánico VFINAL](../VFINAL/README.md)

| Referencia | Aplicación en HORIZON |
| --- | --- |
| FDA 21 CFR § 177.1315 | El diseño identifica las superficies en contacto directo con el plátano y el pimiento y exige material documentado para ese uso, con superficies que permitan la limpieza. La sección se aplica a copolímeros específicos y establece condiciones de uso para el contacto con alimentos. [Texto oficial eCFR](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-B/part-177/subpart-B/section-177.1315) |
| IEC 60529, objetivo IP54 | La bahía electrónica queda separada de la zona de la muestra mediante el tabique. El objetivo IP54 guía las uniones del gabinete, la tapa de servicio y los pasos de cable para limitar el ingreso perjudicial de polvo y proteger de salpicaduras durante la operación y la limpieza. [Catálogo IEC](https://webstore.iec.ch/en/publication/2452) |
| ISO 12100:2010 | El análisis de riesgos organiza las medidas para la carga de muestras, la operación y el mantenimiento. El diseño separa la electrónica de la zona manipulada, incorpora una puerta de acceso a la muestra y reserva el acceso trasero para servicio. Considera los riesgos de bordes, atrapamiento en la puerta, contacto eléctrico y vuelco. [Catálogo ISO](https://www.iso.org/standard/51528.html) |
