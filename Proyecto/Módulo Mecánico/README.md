# Módulo Mecánico

HORIZON reúne una cámara de inspección, una bahía electrónica y un gabinete con acceso por puerta. La configuración de cierre académico está en [VFINAL (Rev E)](VFINAL/README.md). Los STL etiquetados WeatherStation correspondían a una estación meteorológica de ejemplo. Sus originales se conservan en la rama de respaldo.
